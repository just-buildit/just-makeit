- **A generated example that builds the object from a numpy array imports numpy (gh-2844).** An object with an array `init_param` shows its constructor as `W(h=np.zeros(1, dtype=np.float32))`, but each example builder chose for itself whether to write `>>> import numpy as np`, by whether its own method took an array: a scalar object's `step.__doc__`, and its `.pyi` class example, ran as a doctest into `NameError: name 'np' is not defined`. Every synthesized example now passes through one helper that adds the import, once, ahead of the first line that uses `np`; an author's own `@code` is not touched.
