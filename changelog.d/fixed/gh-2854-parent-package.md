- **A standalone component named for a module's package is refused (gh-2854).** `jm module dsp.filt` makes `<pkg>/dsp/` a package, and a standalone `jm object dsp` (`<pkg>/dsp.so`) was accepted beside it in either order, as was one named for a module's `package =`: the package wins the import, so `from <pkg>.dsp import Dsp` raised `ImportError` on a tree `jm status --check` called clean. The verb is now refused before it writes, and a hand-edited manifest at load, naming both and the Python name they claim. A member of another module named like the package, the leaf name (`jm object filt` beside `dsp.filt`) and a module placed in another module's package are unaffected.
