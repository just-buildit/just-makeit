- **`jm app --object <module object>` works without `--module` (gh-1902, gh-2578).** The app read the object's module off `--module` alone, so without it the console face wrote `from . import Biquad` into the root package and the PEP 723 script `from <pkg> import Biquad`, and neither re-exports the class. The module now comes from the manifest for every face, as every member verb's does; a `--module` naming another module than the object's is refused.
