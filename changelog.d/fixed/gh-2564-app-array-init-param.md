- **`jm app --target c` compiles for an object with an array init param (gh-2564).** The C app built its `create()` call from its own list of constructor flags, which skipped array init params, so the call lost each array's pointer and length and did not compile. It now reads create()'s parameters from the one list the C smoke test's call is built from: a flag where there is one, the seed (`NULL, 0` for an omittable array) where there is not. A parameter the app cannot supply and the constructor requires (an array without `default = "[]"`, a `path`, `bytes`, a handle, an `--array-arg`) is refused by `jm app`, naming it, instead of writing an app that cannot construct the object; and a required flag's help no longer reads `(default: None)`.
