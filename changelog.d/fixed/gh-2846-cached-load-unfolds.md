- **A load inside `apply`'s replay now unfolds the manifest as a load from disk does (gh-2846).** `save` folds every unfolding `load` did before it writes, and under `deferred_save` it caches that folded form, so the next `load` returned an object's `[[init_groups]]` with no `init_params`, a template with no instances and an omitted `[project] version` unresolved -- only the `extra_args` rename had been repeated on the cached path (gh-764's rule that the two loads agree, broken for three of four). `_config._unfold` is now every unfolding -- templates, the `extra_args` rename, group expansion, the deferred version -- called by both paths, and `tests/test_gh2846_cached_load_unfolds.py` reads the set of folds `save` performs from its source and holds each to a case where a cached load equals a disk load.
