- **A test run that collects nothing fails `jm test` and the examples gate (gh-2642).** pytest's exit 5 (no tests collected) was read as a pass by `jm test` and by `run_generated_pytest`, a reading written for a functions-only project with no Python test, a shape gh-2127 and gh-2640 removed: every project now carries a test, so an empty run means the tests are gone. `jm test` and the examples gate now fail it, with an `error:` line naming the empty run, and so does `jm test`'s unittest fallback, which exited 0 on an empty run before Python 3.12. Every pytest and unittest run in jm goes through one helper that asks each caller whether an empty run passes; only `jm bench` says yes, for a project with no Python benchmarks.
