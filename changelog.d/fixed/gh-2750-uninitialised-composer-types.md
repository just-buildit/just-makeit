- **Reading an un-initialised composer `Segment`, `Timeline` or `Composer` no longer crashes (gh-2750).** Each type is a base type built by `PyType_GenericNew`, so `Seg.__new__(Seg)` (or a subclass whose `__init__` skips the base's) held a NULL `sources` / `segments` / state, and `Seg.sources`, a flat single-source accessor, a Timeline's `len` / iteration / `add`, and a Composer's `segments`, `repeat`, `to_json` and `compose` read through it and segfaulted. Each type now has its own `tp_new`: a Segment's `sources` and a Timeline's `segments` start as the empty list (so no reader guards it, and a flat accessor raises its usual "only on a single-source" `AttributeError`), and a Composer is born closed, so every method refuses with the `RuntimeError` a closed one raises until `__init__` opens it. A compiled test drives every reader of each.
