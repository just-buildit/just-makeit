- **A name declared twice in one C struct or parameter list is refused (gh-2112).** jm accepted a state field, an init param, a method or function param, or a record field named twice, both on the command line (`jm new --object o --state g:double:1 --state g:double:2`, `jm method ... --param a:int --param a:int`) and in a hand-written manifest. It then wrote a duplicate struct member or a redefined parameter, and `make` failed in the compiler. Every command now refuses it in one `error:` line naming the list and the name, and leaves the project as it was. `jm new` and `jm object` refuse before writing anything, so no half-made project is left behind. A state field and the init param that sets it may still share a name.
