- **A verb no longer silently erases your statements from a module's own CMakeLists (gh-2114).** `jm object x --module m`, `jm function`, `jm method` and `jm remove object` all rewrite `native/src/m/CMakeLists.txt` whole, and none of them went through the check `jm apply` makes before it does the same. An `add_library(m_helper OBJECT ...)` you added there was erased with no message, and so was any other statement. Any root line wiring the library was left naming a target that no longer exists, which cmake rejects at configure time. Each of these verbs now asks the same questions `apply` asks, through the same code. It refuses to erase an OBJECT library, leaves the project as it was, and names the `m_extra.cmake` hook the library belongs in. For any other statement it drops, it prints gh-1351's warning naming the statement and the hook.
