- **Every app imports what its package exports (gh-2063).** An object app named its class after the component, ignoring `class_name`; a function app's console face imported `from .<module id>`, wrong for a dotted module, and its PEP 723 face from the module id's path, wrong once the module declares `package`. Every face now imports the class or function from the package that re-exports it, under the name that package exports.
