- **An `int` setter on a handle, capsule or composer row that declares no `error` is refused (gh-2813).** gh-2302 refused it on an object property; gh-2214 let a handle field's `writable_fn`, a capsule module's writable property and a composer setting's `setter_fn` declare `error`, but a row that declared none still called an `int` setter as a bare statement, so a value the core refused was accepted in Python. `apply` and `status --check` now read the backing header (and the project headers it includes) through the object face's one predicate, and refuse before writing, naming the row and the two ways out: declare `error`, or make the setter `void`.
