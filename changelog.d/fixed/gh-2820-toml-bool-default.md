- **A TOML boolean `default` no longer crashes `apply` (gh-2820).** `default = true` is valid TOML and the natural spelling for a `bool` field, but a default is C source text jm reads as a string, so `apply` died with `AttributeError: 'bool' object has no attribute 'strip'` (a number or a list did the same). `load` now walks every row that carries a `default` once: a bool on a `bool` row is respelled `"true"` / `"false"` (never `str(True)`, which gh-2137 refuses), and any other non-string -- a number, a list, a bool on a non-bool row -- is refused in one `error:` line naming the row, from `apply`, `status --check` and every other command that loads the manifest.
